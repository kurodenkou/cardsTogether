# cardsTogether

Multiplayer card games to play with friends in the browser. Create a room, share the code, and add computer players to fill empty seats.

## Games

| Game | Players | Notes |
| --- | --- | --- |
| Blackjack | 2–8 | Beat the dealer |
| Texas Hold'em | 2–8 | Blinds, betting, showdown |
| Hearts | 4 | Pass 3 cards (left/right/across/none), avoid hearts & Q♠, shoot the moon; game ends at 100 |
| Spades | 4 | Partners (across from each other), bidding incl. Nil, bags; first team to 500 |
| Crazy Eights | 2–8 | Match suit or rank, 8s are wild; winner scores the cards left in other hands |
| Solitaire | 1 | Klondike |
| FreeCell | 1 | All cards face-up |

Hearts and Spades need exactly four players — any empty seats are filled with bots when the game starts.

## Running

```bash
npm install
npm start
```

Then open http://localhost:3000.
